Two phones, one board

A working model of the shared floor plot, running entirely in this page — nothing is deployed and nothing leaves your machine. The box in the middle is the same merge code the server runs. Plot a table on one phone and watch the other.

What to notice: edits to different tables both survive — the board merges per table, not per document. Edits to the same table resolve by arrival order at the server, never by the phone's own clock. And a phone that goes offline keeps working, then catches up when it comes back.
